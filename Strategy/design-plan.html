Прокрути
01 — Цветовая система

Палитра,
рождённая из материала

Цвета не придумываются — они берутся из физического мира. Белизна бумаги, теплота дуба, холод металла, чернота тени на дереве. Четыре роли, шесть оттенков, ноль случайных решений.

Ink #0F0E0C · Тексты
Gold #9A7A3A · Акцент
Gold Light #C4A052 · Hover
Gold Pale #F5EDD8 · Фоны
Warm Gray #E8E4DC · Skeleton
Paper #FAFAF7 · Основной фон

Принципы использования цвета

Белый фон — холст, а не пустота. Товар должен дышать.
Золото используется экономно: иконки, акцентные линии, hover-состояния.
Никаких цветных кнопок. Primary = чёрный, Secondary = граница.
Тени — тёплые (rgba(15,14,12,0.08)), не серые.
Градиенты — только радиальные, очень мягкие, создают глубину.
Hover-эффект на карточках: не цвет, а тень + subtle смещение.

Пространственные токены

4px — Базовая единица
16px — Малый отступ (иконки, бейджи)
40px — Средний (между элементами)
80px — Крупный (между секциями)
120px — Героический (padding страниц)

03 — Структура страниц

Семь экранов,
одна история бренда

Каждая страница — не просто информация, а опыт. Пользователь должен чувствовать, что путешествует по пространству, а не листает каталог IKEA.

04 — Дизайн-принципы

Восемь правил
которые нельзя нарушать

Это не вкусовщина — это решения, которые напрямую влияют на конверсию, восприятие бренда и скорость разработки.

◯
Фотография важнее дизайна
Дизайн должен отступать, когда появляется товар. Карточки без лишних украшений, белый или нейтральный фон съёмки, минимум UI поверх фото.
Минимальный размер карточки 400×500px
На hover — второе lifestyle-фото, не оверлей
Тени на фото — только от предмета, не от карточки
⟡
Белое пространство — это контент
Воздух между элементами создаёт ощущение роскоши. Не бойся пустого места — оно работает сильнее, чем плотная упаковка.
Padding секций: min 80px desktop, 48px mobile
Между карточками в каталоге: 24–32px
Ширина контента: max 1280px, центровка
→
Один призыв к действию на экран
Пользователь растерян, когда у него много кнопок. Один главный CTA, остальное — вторичные действия (outline/ghost).
Primary: чёрный фон, белый текст, uppercase
Secondary: прозрачный фон, border, тот же размер
Ghost: только текст + тонкое подчёркивание
∿
Анимация — не украшение, а сигнал
Каждая анимация должна сообщать о состоянии или иерархии. Анимация ради красоты — это шум. Анимация ради понимания — это ценность.
Hover: 300–400ms ease-out, только transform+opacity
Page transition: fade 250ms или slide-up 400ms
Scroll reveal: stagger 80ms, translateY 24px → 0
⊞
Сетка с нарушениями
Строгая сетка создаёт порядок, нарушение сетки создаёт интерес. Выбирай 1–2 момента на странице где элемент выходит за рамки колонок.
Hero-заголовок может перекрывать изображение
Фото в "Философии" уходит за край экрана
Цена товара — крупнее, чем ожидает пользователь
◈
Состояния — это тоже дизайн
Loading, empty, error, success — каждое состояние должно быть спроектировано. Skeleton лоадер обязателен везде где есть async данные.
Skeleton: тот же layout что и контент, pulse анимация
Empty каталог: иллюстрация + предложение расширить фильтры
Error: тёплое сообщение, не технический текст
◐
Mobile first — но не mobile only
Десктоп это 60%+ аудитории в e-commerce премиум сегмента. Проектируй для десктопа, упрощай до mobile. Не наоборот.
Breakpoints: 375 / 768 / 1024 / 1280 / 1440px
Mobile каталог: 2 колонки, фильтры в drawer
Touch targets: минимум 44×44px
⌘
Скорость — часть дизайна
Каждые 100ms задержки снижают конверсию на 1%. LCP < 2.5s, изображения в WebP, lazy loading ниже fold, prefetch при hover.
Blur placeholder для всех изображений
Priority loading для Hero и first-fold изображений
Prefetch страницы товара при hover на карточку
05 — Фазы дизайна

От концепции
до пиксель-перфект

Дизайн и разработка идут параллельно, с опережением в 1 фазу. Пока разработчики реализуют фазу 1 — дизайнер уже работает над фазой 2.

Фаза 01
Исследование и концепция
Неделя 1–2
★ Анализ 5–7 конкурентов (Minotti, Poliform, RH)
★ Customer journey map: дизайнер → магазин → покупка
★ Mood board в Figma: референсы фото, типографики, цветов
★ Определение tone of voice бренда
★ Выбор шрифтовой пары и финальной палитры
Фаза 02
Дизайн-система в Figma
Неделя 2–4
○ Tokens: цвета, типографика, тени, радиусы, отступы
○ Атомы: Button, Input, Badge, Tag, Icon, Avatar
○ Молекулы: ProductCard, FilterChip, SearchBar, Breadcrumb
○ Организмы: Header, Footer, FilterPanel, ProductGrid
○ Все состояния: default, hover, focus, disabled, loading, error
○ Auto Layout для всех компонентов
Фаза 03
Ключевые экраны
Неделя 4–7
○ Главная страница (desktop + mobile)
○ Каталог + все состояния фильтров
○ Страница товара (3 варианта hover-зоны)
○ Корзина + mini-cart drawer
○ Оформление заказа (3 шага)
○ Страница коллекции
○ Личный кабинет (4 раздела)
○ 404 / пустые состояния
Фаза 04
Анимации и микровзаимодействия
Неделя 8–10
○ Прототип Figma: page transitions
○ Спецификация GSAP: timeline для Hero
○ Спецификация Framer Motion: hover + карточки
○ Описание ScrollTrigger-эффектов
○ Передача спецификаций разработчикам
Фаза 05
QA дизайна и итерации
Неделя 11–13
○ Сравнение Figma vs браузер (pixel review)
○ Тест на реальных устройствах (iPhone, iPad, MacBook)
○ A/B тест: 2 варианта карточки товара
○ Accessibility audit: контраст, ARIA, tab-focus
○ Финальный Lighthouse audit
06 — Инструменты

Стек дизайнера
для этого проекта

Не хайп-инструменты, а проверенные решения которые дают максимум результата за минимум времени. Каждый инструмент — на своём месте.

Figma
UI / Дизайн-система
Компоненты, Variants, Auto Layout, Variables для токенов дизайна. Прототипы для анимаций. Dev Mode для передачи разработчикам.
Figma Slides
Презентации клиенту
Представление концептов, mood boards, промежуточные review с командой. Всё в одном инструменте.
FigJam
User flows / Мозговой штурм
Customer journey, sitemap, brainstorming. Интерактивные воркшопы с командой.
Unsplash / Pexels
Placeholder-фото
До появления реального контента. Искать: "wood texture interior", "minimal furniture", "scandinavian design".
Coolors.co
Доработка палитры
Проверка контрастности, генерация оттенков из базового акцентного цвета, экспорт в CSS переменные.
Google Fonts
Типографика
Cormorant Garamond + DM Sans — оба бесплатны. Проверяй через Variable Fonts для оптимизации загрузки.
Contrast.fyi
Accessibility
Проверка WCAG AA / AAA для всех пар текст/фон. Обязательно для золотого цвета на белом — он граничный.
Responsively
Мультидевайсный тест
Одновременный просмотр на 5+ размерах экрана. Незаменим на этапе QA дизайна в браузере.
07 — Чеклист

Перед передачей
в разработку

Дизайн готов к разработке только когда все пункты закрыты. Незакрытый пункт = дыра в продукте, которую придётся чинить дороже.

Компоненты
Все состояния кнопок задокументированы
Карточка товара: 4 состояния (default, hover, loading, sold out)
Формы: все ошибки валидации показаны
Skeleton для каждого async компонента
Модальные окна: overlay, close, mobile fullscreen
Тосты / уведомления: success, error, info
Типографика и цвета
Все токены в Figma Variables синхронизированы
Контраст всех текстовых пар ≥ WCAG AA (4.5:1)
Fluid typography проверена на всех breakpoints
Dark mode (если планируется) — все цвета адаптированы
Адаптивность
Каждый экран в 5 брейкпоинтах (375 / 768 / 1024 / 1280 / 1440)
Мобильная навигация: hamburger menu / bottom bar
Фильтры на мобильном: drawer снизу
Touch targets ≥ 44px на мобильном
Горизонтальные скроллы на мобильном — snap-точки
Передача разработке
Dev Mode в Figma включён для всех frame
Иконки экспортированы как SVG (оптимизированы через SVGO)
Анимации описаны в спецификации (duration, easing, trigger)
Именование слоёв понятно разработчику
Все изображения — placeholder с указанием соотношения сторон
Финальный review с product manager пройден
