1. Концепция и визуальная идентичность
Магазин позиционируется в премиальном сегменте и должен передавать ощущение эксклюзивности, качества и природной эстетики. Интерфейс строится вокруг товара — мебели из дерева и металлического декора.

1.2 Главная страница — эффектные презентации
Hero секция (полноэкранная)
Кинематографичный fullscreen-видео фон с плавным parallax-скроллом. Продукт крупным планом снимается в студии или интерьере, затем монтируется с замедлением. Поверх — минималистичный оверлей с названием коллекции и одной кнопкой CTA. Анимация появления текста — буква за буквой (staggered reveal) с помощью GSAP.
Marquee-лента коллекций
Горизонтальная бесконечная прокрутка названий коллекций / материалов с чередованием нормального и italic начертания. Реализуется через Framer Motion или GSAP ScrollTrigger, скорость замедляется при hover.
Product Spotlight — карточки в сетке
Сетка 2×2 или 3×2 с крупными фотографиями без рамок. При hover — мягкое увеличение фото (scale 1.04) с появлением оверлея с ценой. Плавный переход через CSS transition 400ms ease-out. На мобильных — горизонтальный скролл с snap-эффектом.
Секция "Материалы и философия"
Горизонтальный sticky-скролл — при прокрутке страницы вниз контент движется горизонтально. Три панели: дерево, металл, ручная работа. Каждая — крупная текстурная фотография + короткий текст. Реализуется через GSAP ScrollTrigger + horizontal pinning.
Instagram-галерея / UGC
Masonry-сетка с реальными фото из интерьеров клиентов. Загружается через API или хранится в CMS. При клике — лайтбокс с анимацией масштабирования (scale + fade).
Ключевой принцип: каждый скролл — это событие. Пользователь не листает страницу, а совершает путешествие по пространству магазина.
2. Технический стек
2.1 Frontend — UI / визуальные эффекты
Фреймворк и рендеринг
Next.js 14+
App Router, SSR/SSG/ISR для SEO и производительности. Оптимизация изображений встроена.
TypeScript
Строгая типизация, снижение ошибок при масштабировании
React 18
Concurrent Mode, Suspense для плавных переходов между страницами
Стилизация и компоненты
Tailwind CSS
Utility-first, JIT-компилятор, нет лишнего CSS в продакшне
shadcn/ui
Unstyled headless-компоненты (Radix UI) для фильтров, модалок, дропдаунов
CSS Modules
Для сложных компонентов с уникальными стилями
Анимации и визуальные эффекты
GSAP + ScrollTrigger
Parallax, горизонтальный скролл, stagger-анимации, timeline. Лучший выбор для кинематографичных эффектов.
Framer Motion
Анимации переходов между страницами (Page Transitions), micro-interactions, drag-эффекты для фильтров
Lenis
Плавный инерционный скролл (smooth scroll) — замена стандартному браузерному
Three.js / R3F
3D-превью мебели в отдельных карточках товара (опционально, этап 2)
Работа с медиа
next/image
Автоматическая оптимизация, WebP/AVIF, lazy loading, blur placeholder
Cloudinary
CDN для изображений, трансформации на лету, фокусировка лиц / объектов
video.js / HLS
Стриминг видео для Hero-секции без перегрузки браузера
2.2 Backend — API и бизнес-логика
API-слой
Next.js Route Handlers
API-эндпоинты внутри того же проекта, Edge Runtime для быстрого ответа
tRPC
Типизированный API без REST/GraphQL boilerplate, идеально для монорепо
Zod
Валидация данных на уровне схем (frontend + backend единая схема)
Аутентификация
Clerk / Auth.js
OAuth (Google, Apple), magic link, управление сессиями. Готовые UI-компоненты.
Роли
Покупатель, менеджер, администратор — RBAC через middleware
2.3 База данных и хранилище
Основная БД
PostgreSQL
Реляционная БД: товары, заказы, пользователи, отзывы. ACID-транзакции.
Prisma ORM
Типизированный ORM, миграции, introspection. Идеален с TypeScript.
Supabase
Managed PostgreSQL + Realtime + Auth + Storage. Масштабирование без DevOps.
Поиск и фильтрация
Algolia
Молниеносный full-text поиск, фасетные фильтры, typo-tolerance. InstantSearch React UI.
pgvector
Векторный поиск для рекомендаций "похожих товаров" (семантический поиск)
Кеширование
Redis (Upstash)
Сессии, корзина, rate limiting, кеш частых запросов. Serverless-совместимый.
Next.js Cache
Встроенное кеширование на уровне fetch, ISR для каталога
CMS — контент
Sanity.io
Headless CMS с визуальным редактором. GROQ-запросы, real-time preview, CDN.
Контент в CMS
Описания коллекций, главная страница, блог, SEO-метаданные, баннеры
2.4 Оплата и коммерция
Платёжная система
Stripe
Карты, Google Pay, Apple Pay, рассрочка (Klarna). Webhooks для статусов заказов.
Stripe Elements
Встроенные UI-компоненты для форм оплаты, PCI DSS compliant
ЮKassa (опц.)
Для российского рынка: СБП, QIWI, оплата при доставке
2.5 Инфраструктура и DevOps
Хостинг и деплой

Мониторинг

PostHog

3.2 Система фильтров
Фильтры реализуются как фасетный поиск через Algolia. Состояние фильтров синхронизируется с URL (query params) для возможности поделиться ссылкой. Обновление каталога происходит без перезагрузки страницы — optimistic UI.
Категория
Чекбоксы с счётчиком товаров
Материал
Дуб, ясень, орех, сосна, металл, комбо
Цвет / финиш

Двойной range slider с инпутами

Коллекция
Выпадающий список с превью
Наличие

Сортировка

6. Масштабирование
Архитектура изначально проектируется с учётом роста нагрузки и функциональности без болезненного рефакторинга.
6.1 Горизонтальное масштабирование
Vercel автоматически масштабирует Edge Functions и Serverless Functions
Supabase — managed PostgreSQL с Connection Pooling (pgBouncer)
Algolia — CDN по умолчанию, SLA 99.999%
Redis (Upstash) — serverless, платить только за запросы
6.2 Будущие расширения
Мобильное приложение
React Native + Expo с переиспользованием бизнес-логики (tRPC)
Маркетплейс
Добавление merchant-аккаунтов, Stripe Connect
B2B-кабинет
Оптовые цены, проекты, счета для дизайнеров
AR-просмотр
WebXR API или нативный ARKit/ARCore через приложение
AI-рекомендации
pgvector + OpenAI embeddings для персонализации
Мультиязычность
next-intl, отдельные домены или поддиректории
